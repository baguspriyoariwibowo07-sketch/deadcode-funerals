A single one-sentence entry, written by `main.ts` to `/output/entry.txt` — nothing else.

## The pitch

> DeadCode Funerals: for $0.50 a function, we hold a small ceremony every time your lazy agent deletes code, then email the repo a eulogy so the next model knows it mattered.

## Why this pitch

- **A service nobody sells yet:** the field saturates with Apology-as-a-Service, nap schedulers, standup stand-ins and commit-message rewriters. No title in it contains a funeral, dead code or a eulogy.
- **Absurdly specific, as the brief weighs:** not "code cleanup" — a ceremony, per deleted function, with a eulogy delivered by email to the repo. Every clause narrows the business further.
- **Commercially believable:** a concrete unit price ($0.50 a function) and a real pain underneath the joke — agents delete code silently, and the next model inherits a repo with no memory of what was lost. The eulogy is the audit trail, dressed for a funeral.
- **The buyer is named by the problem:** any team whose agent refactors first and explains never. They are already paying for the deletions; this just makes them official.
- **Tight:** 172 characters against the 200-character gate.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
